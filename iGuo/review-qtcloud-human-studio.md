## 第一眼

信息混乱——一眼抓不住重点。（人写）

## 主诊断

没有一条视觉主次线。数字块、彩色标签、实心靛蓝按钮都拿到最强的一档强调，而真正要人做的决定「通过 / 拒绝」反而是全页最灰最淡的两枚，目光找不到落点。

问题不在元素多，在重的地方不该重、该重的地方没重。

## 证据

1. 右栏底部四枚靛蓝实心按钮（发送问卷 / 发送实训邀约 / 发送笔试 / 生成面试通知，y≈800）是全图最重最连续的一片；决定这封邮件的「通过 / 拒绝」（y≈628）却是浅灰实底与白底灰描边，看着像禁用态。
2. 右上角红字「已拒绝」与下方粉框「自动拒绝」两处在宣告已拒，同一栏往下仍摆着可点的「通过 / 拒绝」、预填的面试岗位与时间、四枚发送按钮——同一屏既说拒了，又说可以安排面试。
3. 顶部四个数字块（50 总邮件 / 12 待处理 / 34 有正文 / 38/50 自动处理）占满整条横带，第一块浅蓝底加靛蓝横条拿到全页最强强调，可它只是计数，与「该处理哪封邮件」无关。
4. 收件箱每行三枚彩色标签并列，红系既表终态又紧挨浅蓝的 `new`；「已通过」在列表是灰字、在右栏是红字位置，颜色没有统一语义。
5. 顶栏右端四枚胶囊与右栏四枚靛蓝按钮构成两处主按钮区，同为高优先动作却互不相让。

## 建议（按影响从大到小）

1. 终态锁动作（安全，代价小）：已拒绝就收起四枚发送 / 生成按钮，只留复议入口。
2. 「通过 / 拒绝」提成主按钮（效率，小）：全页最强样式给这两枚。
3. 演练模式就近化（安全，中）：顶栏英文 `dry_run` 换成动作区横幅「演练模式（不真实发送）」，开启时发送按钮改描边并加「仅预览」角标。
4. 外发加二次确认（安全，中）：问卷 / 实训邀约 / 笔试点击后列清收件人、岗位、时间再发。
5. 数字块加口径与可点线索（辨识，中）：补分母、统一颜色语义、给出可点提示。
6. 列表按状态分组与筛选（效率，中）：待处理优先，`new` 降级为未读才显示。
7. 标题用人不用号（辨识，小）：主标题显示姓名，QQ 号降为副行。

## 结论

**是什么**：招聘筛选网关的邮件筛选界面——左侧邮件列表，右侧一封邮件的详情与动作面板。

**问题在哪**：没有视觉主次线；最重的颜色给了发送按钮与计数块，真正该做的决定最淡。

**先改什么**：先把终态邮件的下游动作锁住（已拒绝就不再摆发送按钮），再把「通过 / 拒绝」提成全页最强按钮。

一句话复述：这张图的问题不是元素多，而是重的地方不该重、该重的地方没重——正是第一眼那句「信息混乱」。
