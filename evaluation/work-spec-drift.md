# 评估：工作规格的重组点

本报告把「工作规格框架完善但细节卡手」的那些点变成可指认的清单，来源是一次文件级草案的评审（操作型草案：工作文档语法一类）。报告只给位置、判据与改法；**定量对比尚未实测**，第三节留了要数的清单与分母口径，数字按条对照后补，不先写估值。

## 主线

**规格写的是治理，缺的是执行。** 它把「谁管得清」这件事做得比较完整（身份、口径、记录归属都有位置），但照它落成一个能跑的东西时会发现：执行侧的字段装不下执行者、判据判不了、声明侧没有「靠什么做」的位置。下面全部结论都由这一条推出。

## 一、两种理解

两边各自面对的需求不同：

- 规格侧要的是**管得清**：一件事有名字、有归属、有记录、谁都不能事后改口径。因此它把重点放在对象身份、事件、账本的不可变性上。
- 执行侧要的是**做得成**：一件事交给谁、靠什么做、判成没成、能不能重跑。因此它要的是执行者、能力、判据、幂等。

同一个词在两边各指一件事，最典型的是「判据」：规格侧指**判定的记录**（谁判的、判成什么），执行侧指**判定的方法**（拿什么谓词去判）。

## 二、定性对比

拿同一件真实工作（一步「人做、机器判」的核对）按两份走一遍：

- 按规格走：这一步只有 `id` / `name` / `description` 三个字段，人做这件事写在 `description` 的一句散话里；谁判写在判据的 `executor`，可判法写的是一句「由平台定义」。落成文件后，问「这一步该谁做」只能读散话，问「怎么判」得到的是「平台会判」。
- 按执行侧要的走：这一步要能答「执行者、靠什么做、判定者、判法谓词」四问，其中判定者与执行者多数时候不是同一方（人做、机器判是常态）。

分野在三处：**账的方向**（记录过去 vs 规定将来）、**成事标准**（不可变 vs 可重跑）、**放行方式**（谁签字 vs 谓词为真）。

## 三、定量对比（待实测，先定分母）

要数的四组，每组写明分母，按条对照后补数：

1. 一站能被机判的属性：分母＝规格里一站的字段数；分子＝其中可判定的字段数（判法是谓词而非散话）。
2. 步骤须人兜底的比例：分母＝规格里给出的步骤数；分子＝其中「判定者是人」必需、无谓词可依的步骤数。
3. 判据可机判条数：分母＝规格里出现的判据条数；分子＝判法写成固定句式、机器能执行的条数。
4. 引用的稳定性代价：分母＝被其他文档引用过的条款数；分子＝其中被改过一次、按「一经引用即不可变」必须换身份的条款数。

口径：以规格仓当前提交为准，逐条抄原文位置，别用转述计数。

## 四、重组点（按锋利程度排）

**必改（规格自相矛盾，或照它做不出来）**

1. **判据只剩判定者**：判据两字段＝`executor` ＋ `description`，`rule` 的判法写成「由平台定义」，等于把可判定性外包。判据应是**谓词 ＋ 判定者**，谓词用固定句式才可机判。
2. **「谁做」无处安放**：执行者组明写「每一步带 `executor`」「执行者内嵌于工作步骤」，而工作步骤的字段表只有 `id` / `name` / `description`——`executor` 只活在判据里。一步「人做、机器判」时一个字段装不下；改法是把**执行者**与**判定者**拆成两个位置。
3. **声明侧缺操作层**：步骤只有一句 `description`，没有「靠什么做」的位置；照它落成文件必然不可测。能力层不是外加花样，是声明侧的缺件。

**要谈（取向问题，等拍板）**

4. **一站不是两件事，是五件**：做什么、靠什么做、谁做、谁判、算不算完。规格把一站压成「站名 + 一句话 + 谁判」。
5. **「一经引用即不可变」把迭代卡死**：账本要死靶子的动机成立，代价却是每改一个字都是新身份（判据句式一天能改三遍）。要的是**定义带版本、账本钉版本号**，不是禁止改动。
6. **只认产出型过程**：规格要求产物有名字与验收规格，幂等、无产物只有状态的操作型（同步、导出、转码）无处归类——两类过程要分开承认。
7. **本体与平台实现捆在每篇三节**（领域属性 / 领域事件 / API 端点）：文件层抄不动，一抄就把事件与端点一起抄走。本体篇与平台篇该分家。

顺带一条便宜功：规格内部自相打架处（字段表与叙述组互相矛盾）不必等重组，先当缺陷提给规格方修掉。

## 五、怎么核

- 逐条对照用规格仓原文位置：`git -C ~/repos/quanttide/domains/quanttide-work/docs/specification ls-files`，一条对应一份文件。
- 计数口径写在第三节各组的分母里；读者照同一份文件自己数一遍应当得到同一组数。
- 判「必改」的验法：把该条款照字面落成一份文件，然后问「这一步谁做」「怎么判」——答不出来的，就是必改。
