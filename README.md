# quanttide-report-of-knowledge-work

量潮知识工作报告——知识工作领域的报告与复盘记录。

## 概述

- `decision/workflow-id.md` —— ADR-0001：工作流的造号锚定与凭证。
- `evaluation/workflow-formats.md` —— 同一件事（招聘流程）在领域规格与适配层两种工作流格式下各长什么样，四个缺口的处置建议。
- `evaluation/work-spec-drift.md` —— 从一份文件级草案反推工作规格的七个重组点，分必改与要谈。
- `evaluation/qtcloud-work-cli.md` —— CLI 现状评估：四组对象在代码里的落法、判据与执行者的类型化。
- `plan/qtcloud-work-cli.md` —— CLI 分层归位方案、定义冻结守卫与决策落地复核。
